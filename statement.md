
# Scope and Target Users

## Scope
This Student Result Management System is a Python application designed to automate the handling of academic records. It covers:
- Adding and deleting student records.
- Entering, updating, and deleting individual subject marks.
- Storing data persistently using a JSON file.
- Calculating total marks, percentage, GPA, and CGPA.
- Performing class‑level analytics (average, max, min, standard deviation) using NumPy.
- Generating topper lists based on total marks.
- Providing a simple, menu‑driven interface suitable for non‑technical users.


## Target Users
- **Teachers / Faculty Members**  
  To manage student results easily without manual calculations.

- **Coaching Institutes / Small Training Centers**  
 a simple and fast system to maintain student's marks and performance.

- **Students (for personal tracking)**  
  Individuals who want to record their academic progress locally.

- **Academic Mini‑Project Developers**  
  for college or school mini‑projects requiring practical implementation of Python concepts.
